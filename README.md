# Competitor

AI-powered competitive intelligence that helps businesses understand what their competitors are changing.

## Overview

Competitor monitors publicly available competitor information and helps businesses identify meaningful changes across websites, pricing, products, content, SEO, and positioning.

## Key Features

- Competitor website monitoring
- Pricing and product change detection
- SEO and content intelligence
- Evidence-backed change analysis
- AI-powered competitive insights
- Email alerts for important changes
- Competitive intelligence reports

## How It Works

1. Add a competitor's website.
2. Monitor publicly available information.
3. Detect and review meaningful changes.
4. Understand what changed, the supporting evidence, and why it might matter.
